# quote_page_check

Маленькая проверка для моего диссертационного помощника. Карточка статьи не должна считаться готовой, если цитата не находится на той странице, которую я указал.

Модуль не читает PDF и не вызывает модель. На вход уже извлечённый текст страницы и строка цитаты. Так его можно гонять в тестах без датасета и без ключа к API.

## Запуск

Из этой папки:

```
python run.py
```

Откроется страница в браузере. Слева текст страницы и её номер, справа цитата. Кнопка «Проверить» показывает один из трёх статусов: цитата нашлась, на странице её нет, поле пустое. Три кнопки под ней подставляют учебный абзац, чтобы не набирать его на защите.

Тесты:

```
pip install -r requirements.txt
pytest
```

Тот же разбор можно вызвать из консоли, если текст уже лежит в файле:

```
python -m quote_check page.txt 3 "фрагмент цитаты"
```

Код возврата 0, если цитата нашлась. 1, если нет или строка пустая. Без аргументов `python -m quote_check` открывает ту же страницу, но тогда нужен `PYTHONPATH=src`. `python run.py` этого не требует.

## Что считаю найденным

Пробелы, переводы строки и регистр схлопываются. Фраза может быть разорвана в PDF по строкам, и проверка всё равно её увидит, если куски идут подряд.

Пустая цитата не проходит. Иначе можно закрыть поле, ничего не вставив.

## Чего нет

- Перенос слова с дефисом на следующую строку (`мет-` / `рики`) я не склеиваю. Это отдельный случай, его легко сломать на настоящих дефисах.
- Цитата, которая начинается внизу одной страницы и заканчивается на следующей, тоже мимо: функция смотрит одну страницу.

## CI

Файл `.github/workflows/ci.yml`. На push и на pull request GitHub Actions ставит Python 3.12, ставит pytest из `requirements.txt` и запускает `pytest`. Деплоя нет: выкладывать некуда, это библиотечка для проверки, не сервис.

Ветка одна, `main`. Отдельный Git Flow с release-ветками мне тут не нужен.
