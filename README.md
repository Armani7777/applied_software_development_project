# Jeny — помощник для научной работы

Локальный черновик главы с библиотекой статей. По образцу Jenni: редактор в центре, источники слева, чат справа. Отличие нарочное: я не хожу в интернет за чужими бумажками и не выдумываю ссылку. Продолжение абзаца, план, пересказ и ответ в чате собираются только из загруженных текстов. У каждой вставленной фразы есть статус `cited` / `unchecked` / `empty` — та же проверка страницы, что раньше была всем модулем.

## Запуск

```
pip install -r requirements.txt
python run.py
```

Страница: http://127.0.0.1:8765/

Из Docker:

```
docker compose up --build
```

## Что нажать на защите

1. Слева уже лежат три учебные статьи.
2. «План главы» — оглавление из библиотеки.
3. «Продолжить» — абзац со ссылками и статусом цитаты.
4. В чате: «что они пишут про номер страницы».
5. Библиотека → PDF или текст своей статьи.
6. Вкладка «Проверка цитаты», если нужно показать старый узкий случай отдельно.

## Тесты и CI

```
pytest
```

GitHub Actions гоняет pytest, собирает образ и проверяет, что страница отвечает. `Jenkinsfile` — те же ступени для локального Jenkins.
